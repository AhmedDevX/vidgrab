ffmpeg notice
=============

VidGrab uses ffmpeg to merge video+audio and to create MP3 files. The
bundled ffmpeg binaries are UNMODIFIED upstream GPL-3.0 builds. Both build
provenances below were verified against the actual shipped binaries.

Windows (bundled inside VidGrab.exe)
------------------------------------
- Binary: ffmpeg n9.0.2-17-g2a571b6068, "win64-gpl-9.0" static build by
  BtbN/FFmpeg-Builds (repository now at FFmpeg-Builds/FFmpeg-Builds),
  release autobuild-2026-09-30-13-08. The zip ships a GPLv3 LICENSE.txt.
- Fetched by windows/vendor/fetch_ffmpeg.*, which pins and verifies the
  zip SHA-256: a0e45723c72141975f51d8666302e614711745f3102b704ca3f82c897a58d278
  (matches the checksums.sha256 published with that release).
- Upstream binary: https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases/tag/autobuild-2026-09-30-13-08
- Corresponding source: FFmpeg git commit 2a571b606854520cf89804d8030c8b328e621689
  (https://github.com/FFmpeg/FFmpeg/archive/2a571b606854520cf89804d8030c8b328e621689.tar.gz)
  plus the build recipes in the FFmpeg-Builds repository at that tag.
  The source archive is also produced as the CI artifact
  ffmpeg-2a571b6068-src.tar.gz next to the exe.

Android (bundled inside the APK, via the youtubedl-android fork 0.18.1)
----------------------------------------------------------------------
- Binary: FFmpeg 7.1.1 (n7.1.1, libavcodec 61.19.101) shared libraries,
  taken from the Termux ffmpeg package. Byte-level verified: the
  arm64-v8a libffmpeg.zip.so inside the Maven Central AAR
  io.github.junkfood02.youtubedl-android:ffmpeg:0.18.1 is SHA-256
  identical (4664a895283f9f31786be39b0c484c1f96631f02c7c7f9c70a4a4a2da324a092)
  to the binary committed in yausername/youtubedl-android master at commit
  f2280ae7d8 "Bump ffmpeg 7.1.1" (2025-09-27), which sourced it from
  Termux. The Termux package recipe at that time (termux-packages commit
  de5f604e60ba, packages/ffmpeg/build.sh) declares
  TERMUX_PKG_VERSION="7.1.1" and TERMUX_PKG_LICENSE="GPL-3.0".
- The embedded CPython is 3.12 (Termux build, PSF-2.0), also verified
  byte-identical (SHA-256 7edecb6c9bd3a94456168d44911d8aea9f917bedef90c320a29500d92ac3eb62)
  between the Maven Central library AAR and the upstream committed binary.
- The engine also bundles QuickJS (MIT, Bellard) as the JavaScript runtime
  yt-dlp needs for current sites; license text in QuickJS-MIT.txt.
- Upstream library: https://github.com/JunkFood02/youtubedl-android
  (GPL-3.0 fork of https://github.com/yausername/youtubedl-android)
- Corresponding source: https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz
  (also produced as the CI artifact ffmpeg-7.1.1-src.tar.xz next to the
  APKs) plus the Termux build recipe at the commit above.
